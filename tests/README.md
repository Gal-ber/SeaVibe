# tests — בדיקות אוטומטיות

- `run-checks.mjs` — הפקודה `npm run check`: כל הבדיקות, עם סיכום בעברית.
- `unit/` — בדיקות יחידה (Vitest): מנוע הציון, נתונים, שפות, שרת הדיווחים, נתוני אמת.
- `*.spec.ts` — בדיקות דפדפן (Playwright) בשלושה גדלים: פריסה, נגישות, שפות, קבלה, בלי רשת.
- `helpers/` — כלים לבדיקות: מסד מקומי ותשובות דוגמה של Open-Meteo.
- `screenshots.mjs` — צילומי מסך לסקירה (`npm run screenshots`).

הבדיקות לא פונות לאינטרנט.
