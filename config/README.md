# config — הגדרות שאפשר לשנות בלי לגעת בקוד

| קובץ | מה יש בו | מתי משנים |
|---|---|---|
| `app.config.json` | המתגים: נתוני דוגמה או אמת, דיווחים במכשיר או בשרת | רק באישור |
| `app.config.remote.json` | אותו דבר, לאתר הבדיקה ב-Cloudflare | רק באישור |
| `scoring.json` | ספי הציון לכל פעילות | אחרי כיול עם איש ים. להעלות `version` |
| `beaches.json` | 7 החופים: שמות, קואורדינטות, נקודה בים | כשמוסיפים חוף |
| `reports.json` | כללי דיווחי השטח (חלון זמן, מינימום, שמירה) | לפי הצורך |
| `texts/he.json`, `texts/en.json` | כל הטקסטים באתר | לשינוי ניסוח. אותם מפתחות בשתי השפות |

אחרי כל שינוי: `npm run check`.
