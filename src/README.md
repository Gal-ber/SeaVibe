# src — הקוד של האתר

- `screens/` — מסכים שלמים (המסך הראשי).
- `components/` — חלקים של המסכים: כרטיס ציון, טבלה שעתית, חיפוש, דיווחי שטח.
- `engine/` — המוח: חוזה הנתונים, בדיקת הנתונים, מנוע הציון, חלון הזמן, שער הנתונים ושכבת הדיווחים.
- `lib/` — כלים קטנים: עיצוב ערכים, מיקום, הגדרות משתמש.
- `i18n/` — החלפת שפה (עברית / אנגלית).
- `data/` — קטלוג החופים והפעילויות (הנתונים עצמם ב-`config/`).

**כלל:** אין כאן טקסט שהמשתמש רואה. כל הטקסטים ב-`config/texts/`.
