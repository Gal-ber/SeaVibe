# מקורות נתונים

כאן נמצאים כל מקורות הנתונים של SeaVibes.

- `sources.config.json` — הרשימה של כל המקורות. רק כאן מופיעות כתובות של ספקים. כל מקור כבוי (`"enabled": false`) עד שהבעלים מאשר.
- `_template/` — תבנית להעתקה כשמוסיפים מקור חדש.
- `mock/` — נתוני דוגמה (יתמלא בשלב 1).

הדפדפן לעולם לא פונה לספקים ישירות. המשיכה תיעשה רק בסקריפט מתוזמן בתיקייה `scripts/` (שלב 5).
